# ETH News Trading Bot — starter

Бот:
- читає Ethereum-новини через Google News RSS;
- перевіряє нові записи кожні 60 секунд;
- аналізує лише нові новини через OpenAI;
- класифікує їх за 12 категоріями;
- ставить оцінку впливу від -100 до 100;
- формує PAPER-рішення LONG / SHORT / NO_TRADE;
- щосекунди оновлює інформацію в терміналі;
- зберігає результати в SQLite.

## Розширений AI-аналіз

AI оцінює потенційний вплив новини на ETH, але не відкриває реальні угоди.
Разом зі старими `category`, `score`, `importance`, `confidence` та рішенням
зберігаються sentiment, relevance, credibility і novelty джерела, охоплення
ринку й активи, напрямок та діапазон руху, часовий горизонт і тривалість,
priced-in/fake probability, urgency, risk, сутності, факти, відсутня інформація
та теги. Короткий зміст і пояснення формуються українською.

Нові значення лежать у додаткових колонках таблиці SQLite `news`; списки
серіалізуються як JSON. Під час запуску `init_db()` ідемпотентно додає відсутні
колонки через `ALTER TABLE`, не видаляючи таблицю чи старі записи.

## Запуск Windows

```powershell
cd eth_news_trading_bot
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Відкрий `.env` і встав свій `OPENAI_API_KEY`, потім:

```powershell
python main.py
```

Після першого нового аналізу детальний блок з'явиться під головною таблицею.
Локальні перевірки валідації та захисних правил (без OpenAI API):

```powershell
python test_analysis_validation.py
```

## Увага

Це стартова PAPER-версія. Вона не відкриває реальні угоди.
Перед підключенням біржі потрібні backtest, контроль ризику, стоп-лоси,
ліміти втрат і захист API-ключів.
